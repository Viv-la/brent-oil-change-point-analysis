# Brent Oil Change Point Analysis

## Project Overview

This project investigates the impact of major geopolitical, economic, and policy events on Brent crude oil prices using Bayesian Change Point Analysis. The objective is to detect structural changes in historical oil prices and associate these changes with real-world events such as conflicts, OPEC policy decisions, economic crises, and global pandemics.

The project forms part of the **10 Academy Artificial Intelligence Mastery – Week 10 Challenge**.

---

## Project Objectives

- Analyse historical Brent crude oil prices.
- Explore trends, volatility, and stationarity.
- Detect structural breaks using Bayesian Change Point Analysis.
- Associate detected change points with significant geopolitical events.
- Develop an interactive dashboard for visualising analysis results.
